# 大亏损个股总结

静态 GitHub Pages 模块，入口为 `large-loss-review/index.html`。首页及成功/失败案例页均有入口。

页面提供个股与日期两种视角；`#calendar` 直达日期日历，`#day=2026-07-28` 可链接到指定日期。

## 日期视角

按用户确认的账户当日收益率严格低于 -2% 筛选。收益率来自原站账户记录，其中 `weekly-trading-review/daily-income.json` 优先于旧周报；原记录与估算默认全部显示并纳入统计，估算保留独立标识，也可手动关闭。初次打开选中当前范围最近的大亏日。缺记录不补零，不用交割现金流或各股交易收益拼接账户日收益。10月30日旧持仓不变情景已被实际成交和收盘持仓估算替换，并作为11月期初权益。

10月26日至30日采用已核实的 `data/account-estimate.json`，11月2日至4日采用周报 `data/summary.json` 的 `partialAccount`。结构化结果保留未四舍五入收益率并优先于旧页面估算；生成时核对“现金＋持仓市值＝收盘权益”“当日权益－前日权益＝当日损益”。页面可展开查看计算过程；均假设无遗漏持仓或额外出入金，不外推缺少成交或期末权益的日期。

`calendar-trades.json` 从用户交割单提取日期、时间、代码、名称、方向、数量及原表行号，保留逐笔成交，只在展示时按日/代码/方向合并。禁止提交原交割单、资金余额、合同编号及成交编号。当前附件为 GB18030 编码的制表符文本，虽然后缀为 `.xls`。

```sh
# 首次导入或用户提供更新的交割单
python scripts/build-loss-calendar.py --trades /path/to/table.xls
# 使用已净化输入重建
python scripts/build-loss-calendar.py
python scripts/verify-loss-calendar.py
```

`calendar-annotations.json` 保存逐日核对的反思与来源片段，明确标注“当日操作 / 持仓延续 / 本轮回看”。日历中的关联亏损交易周期只提供上下文，不自动把完整周期错误复制成当天错误；没有明确证据时保留待归因，正常止损不判错。连续日期呈现相同持仓问题不代表独立犯错次数，错误排行榜仍按个股交易轮次计数。更新后须核对来源锚点、原文证据，以及桌面/手机的月份切换、估算开关、日期详情和个股跳转。

## 更新

日期视角在每个月的日历下方展示本月错误总结，随月份和估算开关联动。只汇总当前范围的大亏日已确认标签，按“日期 × 分类”去重后按出现天数排序，并列出对应标的、当日操作/持仓延续/本轮回看范围及日期详情入口。同一天多个股票的同类错误只计1天；跨日持仓问题可计多天，不当作独立犯错次数。未新增错误标签的大亏日保留单独说明。

使用 Python 3 与 `beautifulsoup4`：

```sh
python scripts/build-large-loss-review.py
python scripts/verify-large-loss-review.py
```

`data.json` 从已公开的周报、月报、个股案例重建。`annotations.json` 保存经逐条阅读的归类；每个标签有必须出现在对应原文中的证据片段。新增记录默认待归因，不自动按关键词判错。修改数据后重新运行核验，并在浏览器检查筛选和来源链接。

## 计算与覆盖

- 阈值为单轮收益率严格小于 -2%，使用未四舍五入值筛选。默认仅已平仓个股，可切换ETF、历史浮亏。
- 同一股票清仓后重开算新轮次；分批与跨周重复成交去重。同一来源真正重复的同秒成交保留其数量。9月月报（覆盖8月中旬至9月底）已人工核对的 FIFO 分轮优先于重新推算。
- 四月采用页面内 `REPORT_DATA` 的逐轮成本及浮亏，含补入的4月17日成本。五月及八月月报补充旧资料；不重复计算四月或九月月报覆盖的闭环。
- 含费数据使用买入支出、卖出净回款；某轮费用不全时整轮都用费用前金额。10月后补交割只能在日期、代码、方向、股数、成交额唯一对应时替换原委托历史；因此星光股份使用含费 -94.49 元，九阳旧仓、万丰、吉大仍为费用前口径。
- 中途浮亏不与随后亏损闭环重复。四月两条成本已知的历史快照单列。最新快照取已核实账户的最后日期，核对剩余股数及FIFO成本；已平仓的襄阳不保留10月29日旧浮亏，文投按11月4日历史收盘估值单列。
- 错误统计单位为“交易轮次 × 分类”，同轮同类只计一次。一轮可多类，百分比的分母为当前全部亏损样本（含正常试错与待归因），不能相加。
- 原文中早期疑问与后续修正同时保留。摘要和标签优先采用后续明确反思：时代为低卡高未等上板确认；万丰、西陇、昊华为切换模式错误；爱仕达、吉大为题材走弱、梯队负反馈仍做龙头；农发、天威等正常试错不判错。页面的“原站个股分析”明确区别于本人原话。
- 这里只汇总已能核算的已发布资料。缺少成本或后续退出记录时不补造收益率。新版周报表格结构不同时回退读取已净化的 data/trades-partial.json，跨周参考成交参与去重。沪工、大业11月完整闭环已纳入，文投只展示有依据的历史快照。
