# 月度复盘的数据要求

用户于2026-10-03明确要求：每次月度复盘都必须以实际交易数据为基础。

1. 先核对券商成交导出、交割单或交易截图，保留日期、时间、证券代码、方向、数量、价格、成交金额、费用和发生金额；截图转录需逐行核对，同时间同价格的成交不能自动去重。
2. 复盘正文前必须包含实际成交概览、逐笔明细、闭合交易净盈亏、跨月成本和未闭合交易。成交数据不足时，可以整理部分复盘，但必须明确覆盖日期和缺口。
3. 用券商发生金额计算含费用净盈亏，收益率以对应买入现金成本为分母。买卖金额的差额、现金余额、闭合交易收益率都不能替代账户月收益率。
4. 跨月交易要补足买入成本并明确归属。卖出月份的完整持有期已实现盈亏与该自然月收益不同；如需自然月收益，还需月初/月末总资产、持仓市值和期间出入金。
5. 未闭合交易仅展示可见数量和成本，缺少期末价格时不计算浮盈浮亏；缺少成本的卖出不纳入盈利排行。
6. 每条交易反思先说明流水能够核验的操作，再补充用户口述判断。成交时间不能自行证明封板、弱转强、条件单执行或完整交易意图；缺少分钟线或后续交易时保留待确认。
7. 未取得完整自然月流水和持仓/资产数据时，不得把口述收益、片段盈亏或现金净流入表述为已核验的整月结果。
