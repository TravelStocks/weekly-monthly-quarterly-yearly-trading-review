# 大利润个股总结

从站内已发布交割和复盘抽取单轮收益率严格大于 +2% 的交易。默认显示已平仓个股和 ETF。首页、亏损模块、成功与失败案例均有入口。

## 更新

在仓库根目录运行（Python + beautifulsoup4）：

```text
python scripts/reconcile-profit-statement.py <本地完整交割单.tsv或文本型.xls>
python scripts/build-large-profit-review.py
python scripts/verify-large-profit-review.py
python scripts/verify-large-loss-review.py
```

两个模块共用 `scripts/build-large-loss-review.py` 中的成交去重、费用匹配和跨期闭环逻辑。传入 `profit` 时仅写本目录，不改亏损档案。默认仍生成亏损档案；盈利入口是轻量包装。

`annotations.json` 保存逐轮核对的摘要、有效做法、原文依据、评价及适用边界。新增有成本数据的盈利轮次自动进入明细，默认待归因，不从盈亏或关键词自动生成成功标签。人工核对后修改 annotations 并重新生成。构建器校验分类依据与评价依据必须逐字存在于相关原文。

## 口径

- 跨周成交去重；同票清仓后再买另算一轮，盈利与亏损轮次不抵销。
- 完整交割单覆盖区间按全部含费发生金额重算，以清仓划分轮次；跨月和同票再次开仓单列。交割单只在本地读取，公开的 statement-rounds.json 保存汇总结果和覆盖范围。
- 159516 按基金公告处理 7 月 10 日除权的一拆二，成本不变。计算使用十进制金额，在四舍五入前筛选。
- 2026年3月11日至11月4日共720笔，闭环215轮。超过2%的个股41轮、ETF 5轮。11月6日生成的周交割单与总表重叠，没有新增成交。11月5日交割待补。
- 每轮同类做法最多计一次，可有多标签。排行榜分母是当前范围的全部盈利样本，不是策略胜率，也不证明因果。
- 秦安股份不合模式、汉森制药运气盈利，依据本人后续明确结论排除成功标签。康强电子仅认可小仓边界；时代万恒只认可兑现，不把后补金字塔原则写成已执行。
- 摘要是依据原站材料的整理判断。初步分析、本人反思和后续修正按原文来源保留；交易结果不能代替过程评价。
